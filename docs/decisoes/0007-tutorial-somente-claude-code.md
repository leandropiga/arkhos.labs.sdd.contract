# 0007 — Tutorial somente com Claude Code (Antigravity fica para outra versão)

- **Data:** 2026-10-14
- **Status:** aceita (diverge do rascunho)

## Contexto

O rascunho traz instruções para Claude Code e para Google Antigravity. O laboratório é executado
só com o Claude Code, então as instruções do Antigravity ficariam sem teste. Além disso, o comando
do rascunho para o Antigravity era de um instalador não oficial.

## Opções consideradas

1. Manter as instruções do Antigravity, corrigidas e marcadas como "não testado".
2. Remover e focar só no Claude Code.
3. Testar os dois agentes em paralelo.

## Decisão

Opção 2. Tudo o que estiver no tutorial foi executado de verdade. Uma **versão futura e separada**
do tutorial, adaptada para o Antigravity, poderá ser lançada depois.

## Consequências

- O setup do tutorial fica mais curto.
- Os artefatos do Spec Kit (constituição, spec, plano, tarefas) não dependem do agente, então podem
  ser reaproveitados na futura versão para Antigravity. Vale guardar essa ideia para a
  retrospectiva.
